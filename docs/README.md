# core-remodel Documentation Suite

Welcome to the documentation suite for **core-remodel**. This project is a complex monorepo running on Cloudflare Workers featuring Astro, Tailwind CSS, shadcn/ui, D1 databases, MCP tools, and AI governance.

- [Routing (`docs/routing.md`)](routing.md) - Comprehensive mapping of the Astro file-based routing and page structure.
